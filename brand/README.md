# Бренд whisper-station

**Идея.** Микрофон в орбите — «станция на связи». Тёмный космос, циановая
орбита и маленькая луна в её разрыве. Иконка приложения — законченная карточка,
иконка трея — тот же мотив, но монохромный глиф.

## Палитра

| Цвет | Где |
|---|---|
| `#101a2e` → `#060a12` | фон карточки, градиент сверху вниз |
| `#5fc4f5` | орбита, акцент |
| `#bfe9ff` | «луна» |
| `#eaf6ff` | основной текст |
| `#8fa0b8` | вторичный текст |
| `#e05a4f` | запись |
| `#e0b050` | ожидание |

В HUD используется тот же циан, плюс градиент ленты `#5fc4f5 → #9aa0ff → #ff9ff0`.

## Иконка приложения

- `app.svg` — мастер, `viewBox="0 0 256 256"`; в системе ставится как
  `/usr/share/icons/hicolor/scalable/apps/whisper-station.svg` (файлы совпадают).
- Поля по краям 8 %: без них меню приложений обрезает скругление карточки.
- Минимальный размер — 32 px. Ниже используйте трей-глиф, а не уменьшенную карточку.
- Пропорции, наклон орбиты и точку-луну не менять: это узнаваемая часть.

## Трей

- `tray.svg` — монохромный глиф 22×22, толщина штриха 1.4.
- Для светлой панели — тёмная краска `#14141a`, для тёмной — светлая `#f2f3f7`.
- Готовые размеры: 16, 22, 32 px, отдельные файлы под каждую панель.
- В приложении трей рисуется кодом (`whisper_station/icons.py`) и меняет цвет
  по состоянию: покой — циан, запись — красный, распознавание — амбра.

## Файлы

| Файл | Что это |
|---|---|
| `app.svg` | мастер-иконка приложения |
| `app-512/256/128/64.png` | экспорты для меню, лаунчеров и витрин |
| `tray.svg` | монохромный глиф трея |
| `tray-light-{16,22,32}.png` | для светлой панели |
| `tray-dark-{16,22,32}.png` | для тёмной панели |
| `board.png` | контактный лист: иконка, размеры, трей, палитра, HUD |
| `make_board.py` | сборка PNG и контактного листа |
| `style-tile.html` | палитра, типографика и образец HUD в браузере |

## Пересборка

```sh
python3 brand/make_board.py
```

Нужен только PySide6 (уже зависимость приложения). Скрипт не рисует иконку
заново — он рендерит `app.svg` и `tray.svg` в нужных размерах.

## Где используется

- иконка приложения: пакет ставит её в `hicolor`, окно и настройки берут её же
  из SVG (`whisper_station/icons.py`);
- трей: `whisper_station/icons.py`, состояния `idle` / `recording` / `busy`;
- HUD: `whisper_station/hud.py`, размер 480×64, градиентная лента.
