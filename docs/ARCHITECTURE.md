# Архитектура

## Контекст

Один пользователь, сессия KDE Plasma 6 на Wayland. Всё локально: микрофон, модель
Whisper на `127.0.0.1:8765`, буфер обмена, вставка через `uinput`. Внешней сети нет.
Сервер распознавания входит в поставку: приложение ставит его в отдельное окружение
и запускает само. Чужой сервер на том же порту поддерживается и не трогается.

## Компоненты

| Модуль | Ответственность | Границы |
|---|---|---|
| `app.py` | `QApplication`, трей, IPC-сокет, хоткей, окно настроек | знает про Qt и сигналы |
| `controller.py` | состояния: idle → starting → recording → transcribing → idle | не трогает Qt-виджеты напрямую |
| `recorder.py` | `pw-record`/`parec` → WAV 16 кГц моно PCM16, полосы осциллограммы | один процесс записи за раз |
| `stt.py` | multipart-запрос к `/v1/audio/transcriptions`, подсказка из словаря, таймауты, ретрай | только loopback |
| `catalog.py` | каталог моделей: размеры, рекомендация по устройству, детект CUDA | без сети и Qt |
| `models.py` | наличие моделей на диске, скачивание через huggingface_hub, отмена | пишет только в каталог моделей |
| `server_env.py` | venv сервера: установка faster-whisper, маркер, версия | не ставит пакеты в систему |
| `server/` | встроенный HTTP-сервер: `/health`, `/v1/models`, `/v1/audio/transcriptions` | stdlib HTTP, без Qt |
| `textproc.py` | пост-коррекция: словарь терминов, филлеры, повторы, пробелы | чистые функции, без Qt |
| `inject.py` | буфер `wl-copy`/`wl-paste`, Ctrl+V через `ydotool`, свой `ydotoold` | не меняет права в системе |
| `hotkey.py` | регистрация в `org.kde.kglobalaccel`, поток `dbus-python` | одна комбинация на действие |
| `service.py` | `/health`, план запуска (своя команда → встроенный сервер → `run.sh`), остановка только своего сервера | чужой процесс не трогает |
| `hud.py`, `settings_ui.py` | HUD записи и диалог настроек | без бизнес-логики |
| `rules.py` | правило KWin, ставящее HUD сверху по центру | только `kwinrulesrc` |
| `config.py`, `paths.py` | TOML-конфиг, пути XDG | единственный источник настроек |

## Поток данных

```
hotkey ──► controller.start ──► service.ensure (сервер) ──► recorder.start
                                                              │ parec
HUD ◄── wave_changed (полосы min/max) ◄───────────────────────┘
hotkey ──► controller.stop ──► recorder.stop (WAV) ──► stt.transcribe
                                                             │ текст
                                                             ▼
                                                   textproc.process_text
                                                   (словарь → филлеры → повторы
                                                    → пробелы → хвостовой пробел)
                                                             │
                                                             ▼
                                                   inject_text ──► активное окно
                                                     │ wl-copy
                                                     │ ydotool Ctrl+V
```

## Потоки

- **Главный (Qt)** — виджеты, меню, IPC, запуск/остановка записи.
- **Чтение аудио** — `recorder` читает stdout процесса и считает уровень.
- **Распознавание** — HTTP-запрос и чистка текста (`textproc`), результат возвращается сигналом в главный поток.
- **DBus (GLib)** — регистрация хоткея и приём активации.
- **Восстановление буфера** — таймер на 1.5 с после вставки, с проверкой содержимого.

## Правила и границы

- Никаких сетевых адресов, кроме `127.0.0.1`/`localhost` (`config.is_loopback_url`);
  сервер тоже слушает только loopback (`ServerConfig.from_env` это проверяет).
- Модель и устройство читаются сервером только при старте: `service.plan()` передаёт их
  через `WHISPER_MODEL`/`WHISPER_DEVICE`/`WHISPER_COMPUTE`/`WHISPER_MODELS_DIR`.
- `prompt` (словарь, до 20 терминов) уходит в модель как `initial_prompt`; пост-коррекция
  в `textproc.py` остаётся вторым слоем и не зависит от сервера.
- Сервер: если порт занят — используем; если нет — поднимаем свой и гасим при выходе;
  чужой не убиваем никогда. Свой сервер выгружается после 30 минут простоя.
- Аудио на диск не пишется (только в памяти), кроме отладочного режима.
- `ydotoold` — дочерний процесс приложения, запускается без root, останавливается с ним.
- Единственный экземпляр: UNIX-сокет в `$XDG_RUNTIME_DIR`, второй процесс не стартует.
- Позиция HUD на Wayland задаётся не приложением, а правилом KWin (`rules.py`).

## Состояния

`idle → starting` (проверка/запуск сервера) `→ recording` (HUD, таймер) `→ transcribing`
(скрыли HUD) `→ inject → idle`. `cancel` из любого состояния возвращает `idle` и
увеличивает поколение — поздние результаты распознавания игнорируются.
