# План разработки

Обновлён: 2026-11-10. Текущая версия — 0.3.1.
Основание: [разбор Handy](HANDY-ANALYSIS.md) и текущие ограничения проекта.

Принципы:

- сначала то, что улучшает саму диктовку (текст, режим, вставка), потом
  обвязка (история, настройки, портируемость);
- никаких новых зависимостей без согласия; SQLite, `sqlite3`, `ffmpeg` —
  только системные/стандартные;
- KDE/Wayland-поведение не ломаем: хоткей, HUD, вставка через `ydotool`,
  один экземпляр, `systemd`/autostart;
- каждая итерация заканчивается зелёными `make lint && make test`, записью в
  `CHANGELOG.md` и ручной проверкой на живой сессии;
- приватность: аудио на диск не пишем, история — только текст, сеть — только
  loopback.

Легенда: **P0** — делаем в ближайшей итерации; **P1** — следующая; **P2** —
после стабилизации; **later** — бэклог.

## Definition of Done

Для любой задачи:

- [ ] код + тесты (unittest, без новых пакетов);
- [ ] `make lint && make test` зелёные;
- [ ] docstring модуля, логирование вместо `print()`, импорты без циклов;
- [ ] обновлены `README.md`/`docs/ARCHITECTURE.md`/`docs/DECISIONS.md`, если
      меняется поведение или конфиг;
- [ ] ручная проверка на KDE Plasma 6 / Wayland: хоткей, HUD, Esc, вставка в
      обычное окно и терминал, отмена;
- [ ] нет висящих `pw-record`/`parec`/`ydotoold` после выхода.

## Итерация 0.4.1 — «Надёжность» (P0/P1)

Цель: убрать накопленные мелкие дефекты до истории и больших UI-работ.

- [ ] **HUD timer leak:** `Hud.finish()` не пересоздаёт `QTimer`, а
      останавливает/сбрасывает существующий; убрать дублирующиеся соединения.
- [ ] **Ротация лога:** `RotatingFileHandler` (5 МБ × 3) вместо растущего
      `app.log`; проверить, что `log --open` показывает актуальный файл.
- [ ] **Временные файлы recorder:** закрывать `_stderr` старого процесса при
      ретрае, не оставлять `whisper-station-*.log`.
- [ ] **Конфиг: версия и миграции.** `version = 1` в TOML, идемпотентные
      миграции при чтении, тест на старый файл без новых полей.
- [ ] **`doctor`:** hook, история, выбранный микрофон, синтаксис ydotool,
      `ffmpeg` (для будущей транскрипции файлов), ротация лога.
- [ ] **Буфер:** восстанавливать картинку, если текста не было; очищать
      только если буфер был пуст; не трогать чужой буфер при ошибке.
- [ ] **Глобальный cancel-хоткей** (P1): второй action в KGlobalAccel,
      по умолчанию выключен; позволяет отменить запись без фокуса HUD и
      открывает путь к HUD без фокуса.
- [ ] **Ошибки:** одно уведомление на сбой (не дублировать tray + notify),
      текст ошибки копируется в лог; без изменения публичного API.
- [ ] **Тесты:** HUD smoke (offscreen), ротация лога, миграция конфига,
      doctor на фикстурах.

**Приёмка:** после 20 циклов записи нет роста числа таймеров/файлов; лог не
растёт бесконечно; старый конфиг читается; cancel-хоткей отменяет запись.

- [ ] Транскрипция файлов из GUI: `ffmpeg` → 16 кГц mono WAV → сервер;

      `optdepends` PKGBUILD.
- [ ] Восстановление картинки в буфере (если не сделано в 0.4.1).
- [ ] Исследование: `org.freedesktop.portal.GlobalShortcuts` для GNOME/

- [ ] Исследование: X11 (`xclip`/`xdotool`) — только если будет спрос.

файл `.mp3/.m4a/.wav` транскрибируется из GUI; на KDE ничего не сломалось.

## Бэклог (later)

- Per-app правила: класс окна → режим вставки/auto-submit (в Handy нет;
  нужен надёжный способ узнать активное окно на KWin).

- Профилировать preview: 8 с аудио каждые 1,8 с; при длинной записи
  уменьшить окно/интервал или перейти на инкрементальные запросы.

- Стриминговый предпросмотр, если появится streaming-эндпоинт.
- Коды ошибок/notice-модель, если появится en-локаль.
- Flatpak/Debian/Fedora, матрица тестов KDE/GNOME/Hyprland.
- Model-level словарь: согласовать с владельцем `.whisper-local` поле
  `prompt`/`hotwords` в `server.py` (сейчас read-only).

## Что не делаем

- Tauri/React/Rust-переписывание, модели внутри процесса, engine supervisor.
- Облачная LLM-постобработка (нарушает loopback-only).
- Аудио в истории (нарушает «аудио не пишем на диск»).
- Онбординг, updater, 26 локалей, What's New.
- `reliable paste` на Wayland (нет receipt), оверлей без фокуса без
  глобального cancel.
