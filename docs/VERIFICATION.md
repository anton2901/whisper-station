## Что проверялось вживую

- Регистрация в `org.kde.kglobalaccel`: `shortcutKeys` → `Meta+Alt+D`, запись
  `[whisper-station] toggle=Meta+Alt+D,Диктовка` в `~/.config/kglobalshortcutsrc`.
- Нажатие `Meta+Alt+D` через `ydotool` (uinput) → сигнал `globalShortcutPressed` → запись.
- Вставка: `wl-copy` + `ydotool key 29:1 47:1 47:0 29:0` в сфокусированное окно,
  кириллица без потерь; буфер восстановлен.
- `ydotoold` поднят приложением от обычного пользователя (ACL `/dev/uinput`), погашен при выходе.

## Свой сервер и модели (2026-11-15)

Проверено на CachyOS, Python 3.14.10, faster-whisper 1.2.1 в venv приложения;
модель бралась из общего кэша HuggingFace, GPU в момент проверки был недоступен.

|---|---|---|

| Повторная установка | `server install` без `--force` | сообщает версию и путь, ничего не качает |
| Запуск сервера | `python -m whisper_station.server` | `/health` = ok, модель загрузилась за 3.5–4.7 с |

Замечания:

- PyAV 1.2-совместимый API ломал `faster_whisper.decode_audio` на этой версии —
  WAV разбираем сами (`wave` + `numpy`), PyAV в пути не участвует.
- Ошибка внутри обработчика раньше рвала соединение без ответа; теперь 500 с текстом.
- `large-v3-turbo` на CPU в 3–4 раза медленнее `small` — поэтому CPU-дефолт `small`.

| Проверка | Результат |
