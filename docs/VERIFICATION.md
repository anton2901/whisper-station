## Что проверялось вживую

- Регистрация в `org.kde.kglobalaccel`: `shortcutKeys` → `Meta+Alt+D`, запись
  `[whisper-dictate] toggle=Meta+Alt+D,Диктовка` в `~/.config/kglobalshortcutsrc`.
- Нажатие `Meta+Alt+D` через `ydotool` (uinput) → сигнал `globalShortcutPressed` → запись.
- Вставка: `wl-copy` + `ydotool key 29:1 47:1 47:0 29:0` в сфокусированное окно,
  кириллица без потерь; буфер восстановлен.
- `ydotoold` поднят приложением от обычного пользователя (ACL `/dev/uinput`), погашен при выходе.

## Вставка в терминал (2026-11-08)

| Проверка | Результат |
|---|---|
| Ctrl+V в Konsole | ничего не вставляет |
| Ctrl+Shift+V в Konsole | вставляет содержимое буфера |
| Диктовка с `paste_shortcut = ctrl+shift+v` | текст попал в Konsole (проверено по экрану) |
| Буфер после вставки | остаётся с текстом диктовки (`restore_clipboard = false` по умолчанию) |

Причина исходного случая (запись 95.7 с, 11:32): распознавание прошло, но Ctrl+V ушёл в
терминал, а буфер вернулся к прежнему — текст пропал. Теперь ничего не теряется.

## Не проверено

- Физическое нажатие клавиши человеком (использовалось синтетическое событие через uinput).
- Другие DE/композиторы (GNOME, Hyprland) и X11 — код рассчитан на KDE Wayland.
- Push-to-talk, портал `GlobalShortcuts`, многомониторное размещение HUD.
- Закрытие/перезапуск DSH при работающем приложении — проверено только отсутствие
  зависимостей в коде (общий сервер не затрагивался).
